# Young Boy Studio

`young-boy-studio.svg` is the scalable studio artwork used in OC Pet’s About page, first-launch analytics choice, and the public website. It is studio branding, separate from the CC0 pet-character library.

Created with the built-in image-generation tool. Final prompt:

> Use case: logo-brand. Asset type: original studio logo image used on a cozy desktop companion game's About page and website. Brand exact text: "Young Boy Studio". Create a polished friendly compact emblem of a curious young boy with simple dark hair looking toward a small star, integrated with a warm rounded wordmark reading exactly "Young Boy Studio". Gentle hand-drawn illustration, clean bold shapes that remain readable at small sizes, muted sage green, warm cream, soft golden yellow and dark forest outlines, suited to a cozy pet app. Square composition with generous transparent margins, emblem above neatly stacked readable studio name. Truly transparent background, no mockup, no additional words, no watermark. Original independent game studio identity.

The original full-resolution generated image remains in `young-boy-studio.png`. The SVG is a genuine vector trace (paths, not an embedded bitmap), created using VTracer 0.6.15 with color/spline tracing, 5-bit color precision, layer difference 24, speckle filter 16, and path precision 2. Fine paper-like texture is simplified in the scalable version. Low-opacity fringe pixels (alpha below 160) were excluded before tracing to prevent dark speckles around the transparent edge. Both formats have transparent backgrounds.
